# ADHD Focus Flow Protocol

## Propósito
Maximizar la entrega de valor y blindar el estado de concentración (*flow state*) del desarrollador. Este protocolo corta de raíz la sobrecarga cognitiva, prohíbe explicaciones innecesarias y gestiona los desvíos imprevistos de forma estructurada.

---

## 1. Reglas Innegociables de Comunicación

* **Cero muros de texto:**
  * Prohibidas las introducciones ("¡Claro!", "Con gusto te ayudo"), resúmenes teóricos o despedidas.
  * Directo al grano: ruta de archivo, bloque de código exacto y comando de terminal.
  * Límite estricto: máximo 3 viñetas breves si se requiere explicar una decisión técnica.
* **Encabezado obligatorio de anclaje (Context Anchor):**
  Cada respuesta debe iniciar con este bloque exacto de 3 líneas para eliminar la pérdida de memoria de trabajo:
  ```text
  [TERMINADO]: <último cambio verificado en una frase corta>
  [ACTIVO]: <la única tarea que se está ejecutando ahora mismo>
  [SIGUIENTE]: <el paso inmediato posterior>
  ```
